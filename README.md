# FairShare

# About
FairShare is an open source app used to allow users to easily track and split bills or payments within custom made groups with other users. Its an easy way for groups who pay together often, but don't want to go through the hassle of calculating how much everyone owes each other all the time. 

This is a project made by Group 2 - FairShare in association with The University Of Auckland SOFTENG 310.

# Technology Stack
**Language**: Java, Javascript   
**Backend**: Spring Boot + Spring MVC  
**Frontend**: React (HTML, CSS) 
**Database**: MySQL  
**Data access**: Spring Data JPA/Hibernate  
**Build tool**: Maven  
**Testing**: Backend: JUnit, Mockito, Testcontainers (Docker)
**Frontend**: Vitest + (Cypress)  
**CI**: GitHub Actions  
**Code quality**: SonarCloud and Snyk
